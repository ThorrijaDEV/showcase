## Cross-Language Validation

12 tests in `the-box-validation.test.ts` compare TypeScript structural
properties against Python reference values generated by
`validate_box_python.py` using controlled fixtures (hand-built substrates,
not `State.random()`).

**Validated equivalences:**
- Node count, arc count
- In-degree / out-degree distributions and moments
- Beta0 / Beta1 (Euler-exact)
- Connected components count
- Modularity (deterministic Louvain)
- Lineage depth (max, mean), descent arcs
- Identity metrics (fusion classes, fused fraction)
- All 14 named observables
- Rule applicability (which rules are enabled at which anchors)
- Null model structural properties (rewire preserves degrees; shuffle
  preserves tag multiset; homogeneous erases tags and normalises weights)

**Not byte-compatible:** Graph hashes, canonical keys, unit_hash outputs,
and experiment fingerprints differ between Python and TypeScript due to the
BLAKE2b implementation difference. See `TECHNICAL_LIMITATIONS.md`.
